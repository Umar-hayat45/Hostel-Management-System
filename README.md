Hostel Management System
A desktop application for managing hostel records, built with Java and JavaFX using the MVC pattern.

Features
Dashboard: Overview of total students, rooms, revenue, and pending complaints.

Students: Add, update, and manage student details and fee records.

Rooms: Track room capacity, pricing, and occupancy status.

Payments: Record student fee transactions.

Complaints: Log and update maintenance or administrative issues.

Tech Stack
Java

JavaFX

Maven

How to Run
Clone the repository:

Bash
git clone https://github.com/Umar-hayat45/hostel-management-system.git
Open the project in your IDE (IntelliJ/Eclipse) or navigate to the directory in your terminal:

Bash
cd hostel-management-system
Build and run using Maven:

Bash
mvn clean javafx:run
